I have created this 'Python-Financial-Scripts-2025' repository to provide financial scripts examples relating to the stock market.  I am using the Yahoo Finance website to keep track of a stocks history and the dividendmax website for obtaining accurate historical dividend data.

I will be covering different financial areas like Japanese Candlesticks, Simple Moving Averages, and Fibonacci Retracement etc.

The main purpose of these financial scripts is to allow the user to keep a better track of their investment portfolios.  I am using the ticker symbol HSBA.L (HSBC Holdings plc) as an example in these scripts.

The ticker symbol can easily be changed to another e.g. FRES.L (Fresnillo Plc).

I will be creating several python scripts using the stock 'HSBC Holdings plc' as an example to demonstrate different financial topics including:

1. HSBA.L Stock History
2. HSBA.L Japanese Candlestick Stock Charts
3. HSBA.L Japanese Candlestick Stock Purchase and Price Charts
4. Simple Moving Averages (5 - 10 Day SMAs)
5. Simple Moving Averages (20 - 50 Day SMAs)
6. Fibonacci Retracement
7. HSBA.L Dividend History
8. HSBA.L Dividend Bar Charts
